ROSTR Agent Framework

From Sybill's SOPs to production agents.

The ROSTR system translates your operational processes into intelligent agents using a structured 4-step pipeline.

01

JTBD Analysis

Map Sybill's GTM jobs — what does inbound routing actually need to accomplish? What does outbound research require? Identify the real outcomes.

02

Intent Extraction

Feed Sybill's existing processes into the Natural Language Prompt assistant. Extract the intent behind each workflow step — what you actually want done.

03

Agent Architecture

Design the agent scaffold: prompt layers, tool connections (HubSpot, Clay, Apollo), state management, and orchestration logic using ROSTR primitives.

04

Build & Deploy

Develop each agent, test against real Sybill data, deploy to production with monitoring. Every agent gets a defined input/output contract and failure handling.

Sybill ROSTR Agents

Five production agents designed for Sybill's revenue stack.

🎯
Inbound Intent Router Classifies every Contact Us submission into: Sales, Partnership, Support, Press, Career, Other. Returns intent + confidence + routing recommendation. Updates HubSpot properties automatically.
🔍
Account Researcher Takes a target account, generates: what they do, who they sell to, recent priorities, operational pain, and 3 factual signals worth contacting about. Output feeds directly into outbound sequences.
📊
Contact Ranker Maps contact titles to Sybill's buying committee (RevOps → CRO → Sales Manager → AE Champion). Scores by role fit, seniority, and buying signal strength.
✉️
Email Drafter Writes body-only outbound or inbound replies. References one concrete signal and one operational pain point. Ends with a clear next-step question. No fluff, no templates.
🔧
CRM QA Auditor Checks for missing fields, routing errors, lifecycle mismatches, and broken handoffs. Outputs a prioritized fix list. Runs on schedule or triggered by deal stage changes.
Claude Skill Setup

Reusable skills that compound over time.

Not random prompts floating in Slack — structured skills with defined inputs, outputs, tone guardrails, and ownership so operators and agents can use them consistently.

Classification Skill

Inbound Intent Classifier

InputForm submission text, company name, contact title
Output{ intent, confidence, routing, lifecycle_action }
ToneAnalytical, zero-ambiguity structured output
GuardrailNever classify uncertain intent as Sales — default to Other with flag
Research Skill

Account Research Brief

InputCompany domain or name
Output{ summary, icp_fit, pain_hypothesis, signals[], priority }
ToneConcise, operator-grade — facts only, no marketing speak
GuardrailMust cite at least 2 verifiable signals per account
Drafting Skill

Outbound Email Writer

InputContact name, title, company, research brief, pain hypothesis
OutputEmail body only — no greeting, no sign-off
ToneDirect, intelligent, slightly provocative. Seller-first language.
GuardrailMax 4 sentences. Must end with one specific question, never "let me know"
QA Skill

CRM Hygiene Auditor

InputDeal record with all properties
Output{ issues[], severity, fix_actions[], owner }
ToneClinical, actionable — each issue gets a fix instruction
GuardrailNever modify data directly — output recommendations only
"Every Claude skill gets a defined role, input schema, output contract, tone guardrails, examples, and failure handling — so an operator or future agent can run it the same way every time."
