Data Flow

1
Call ends HubSpot meeting webhook fires. Workflow grabs meeting metadata + attendee emails.
2
Transcript ready Polls Avoma until transcription_uuid + transcript array are present. Up to 10 retries.
3
Context loaded Pulls associated deal from HubSpot. Parses 30+ properties into a clean context object.
4
5 agents in parallel Follow-up email, missed questions, competitor intel, LinkedIn post, expansion analysis — all fire simultaneously.
5
RAG-grounded outputs Country and competitor agents query Azure AI Search for facts before generating recommendations.
6
Digest assembled All outputs merged into a 9-section HTML email with copy/paste-ready content.
7
Distribution Email to rep + management cc. Plain-text note created on the HubSpot contact.

Components

01

Meeting Webhook

HubSpot meeting completion fires the workflow. Captures meeting timestamp + attendees.

02

Transcript Polling

Polls Avoma API with retry logic — handles transcript readiness lag gracefully.

03

Deal Context Extractor

Pulls 30+ HubSpot deal properties. Normalizes into agent-ready stage context.

04

Agent 1 — Follow-Up Email

Country-grounded consultative email. Maps each country need to Atlas capability.

05

Agent 2 — Missed Questions

6-category analysis of questions the rep should have asked. Plus country blind spots.

06

Agent 3 — Competitor Intel

Detects competitors mentioned. Pulls 2–3 fact-based counter-points per competitor from RAG.

07

Agent 4 — LinkedIn Post

Generates 2026-algorithm-optimized LinkedIn post from a single insight.

08

Agent 5 — Expansion Analysis

Detects multi-country signals. Recommends TalentEdge follow-on motion when warranted.

09

RAG Knowledge Base

Azure AI Search with country + product + competitor indexes. Hybrid query.

10

HTML Digest Builder

Merges all 5 agent outputs into a styled 9-section digest.

11

Email Distribution

Outlook to rep + management cc.

12

CRM Note Writer

Plain-text version saved as HubSpot note on the contact record.
