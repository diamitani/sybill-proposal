Data Flow

1
Form submission Prospect fills out a form. Webhook fires in <1 second.
2
Intent classification AI reads the actual message and assigns one of 7 categories using priority rules.
3
CRM hygiene Reason for contact updated. Lifecycle stage corrected only when needed.
4
Response drafting If sales-qualified, AI drafts a brand-correct, country-aware email body.
5
Rep handoff Draft lands in CRM. Rep opens HubSpot, reviews, sends. Total time: <30s.

Components

01

Webhook Capture

Secure POST endpoint for any form provider. Preserves the full payload end-to-end.

02

AI Classification Agent

GPT-5 with priority rules. Outputs one of 7 canonical intent categories.

03

Lifecycle Correction Logic

Conditional CRM writes — only updates when AI corrected the original selection.

04

Response Drafting Agent

Brand-voice email writer with country handling and calendar CTA enforcement.

05

Azure AI Search RAG

Optional knowledge-base grounding for product, country, or compliance Q&A.

06

CRM Write-Back

Drafted email body + processing flag written to custom HubSpot properties.
